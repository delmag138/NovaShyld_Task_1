# NovaShyld_Task_1
Task 1: Cybersecurity Fundamentals & Practical Awareness

## 📌 Project Overview
This repository contains the technical report for Task 1 of the NovaShyld Cybersecurity Analyst program. The report covers core information security principles, threat modeling methodologies, social engineering tactics, and an in-depth analysis of a real-world security breach.

---

## 🎯 Key Topics Covered

### 1. Security Principles & Threat Modeling
* **The CIA Triad:** Detailed analysis of Confidentiality, Integrity, and Availability controls.
* **Threat Vectors & Social Engineering:** Examination of attack pathways, psychological manipulation tactics (Authority, Urgency, Intimidation), and attack delivery methods (Phishing, Smishing, Vishing, Pharming, Typosquatting).
* **MITRE ATT&CK Framework:** Mapping adversary tactics and techniques to understand attack lifecycles and build effective mitigation strategies.

### 2. Real-World Breach Case Study: Uber (2022)
* **Attack Path:** Analysis of initial credential compromise via dark web access brokers and Multi-Factor Authentication (MFA) fatigue bombing.
* **Privilege Escalation:** Exploitation of hardcoded plain-text credentials in internal network shares to gain administrative access to Privileged Access Management (PAM) infrastructure.
* **CIA Impact & Mitigation:** Evaluation of confidentiality and operational impacts alongside defensive recommendations (FIDO2/hardware security keys, secret scanners, least privilege policies).
